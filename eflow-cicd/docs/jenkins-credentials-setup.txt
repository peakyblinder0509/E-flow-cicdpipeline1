# Jenkins Credentials Setup
# ===========================
# Jenkins → Manage Jenkins → Credentials → System → Global credentials → Add

CREDENTIAL ID       | TYPE                          | DESCRIPTION
--------------------|-------------------------------|----------------------------------
github-creds        | Username with Password        | GitHub username + Personal Access Token
aws-creds           | AWS Credentials               | AWS Access Key ID + Secret Access Key
harbor-creds        | Username with Password        | Harbor robot account username + secret
grafana-creds       | Username with Password        | Grafana admin username + password
SonarQube           | Secret Text                   | SonarQube auth token (via SonarQube plugin)


# SonarQube Plugin Setup
# ========================
# Jenkins → Manage Jenkins → Configure System → SonarQube Servers
#   Name        : SonarQube
#   Server URL  : http://<SONAR_IP>:9000
#   Auth Token  : (add token from SonarQube → My Account → Security)


# NodeJS Tool Setup
# ==================
# Jenkins → Manage Jenkins → Global Tool Configuration → NodeJS
#   Name    : NodeJS-18
#   Version : 18.x
